# La Liga del Saber · 3.º C

Dos aplicaciones educativas originales y gratuitas para repasar la Situación de Aprendizaje 1 de tercero de Primaria, con evaluaciones previstas entre el 26 y el 30 de octubre de 2026.

## Acceso
- [Portada](https://cargamelo.github.io/ExamenMateLengua1/)
- [Matemáticas](https://cargamelo.github.io/ExamenMateLengua1/matematicas-sda1.html)
- [Lengua](https://cargamelo.github.io/ExamenMateLengua1/lengua-sda1.html)

Estas URL solo funcionan cuando **GitHub Pages está activado** en el repositorio.

## Activar GitHub Pages
1. En GitHub, abrir **Settings → Pages** del repositorio.
2. En **Build and deployment → Source**, seleccionar **Deploy from a branch**.
3. Seleccionar la rama **main** y la carpeta **/(root)**.
4. Pulsar **Save**. Visitar la URL cuando GitHub indique que está publicada.

## Contenido
**Matemáticas**: lectura de números hasta 9.999, descomposición, comparación, ordenación, ordinales y cardinales, sumas y restas, simulacro de 20 preguntas y repaso de errores.

**Lengua**: sinónimos, antónimos, 30 escenas de comunicación, mayúsculas y puntos, 12 lecturas con seis preguntas, diez dictados, diez fragmentos de lectura expresiva y Memory de parejas.

## Privacidad y compatibilidad
No hay anuncios, registro ni servicios remotos. El progreso se guarda en el navegador mediante localStorage y no se sincroniza entre dispositivos. Las voces dependen de las capacidades del navegador; existe alternativa para dictar con un adulto.

## Archivos
- index.html: portada.
- matematicas-sda1.html y lengua-sda1.html: accesos independientes.
- estilos.css: diseño responsive.
- contenidos.js: temarios y bancos de actividades.
- juego.js: lógica de juego, simulacros, correcciones y guardado.
- .nojekyll: publicación estática directa.

## Validación
Se ha comprobado la sintaxis JavaScript, la generación de preguntas y respuestas correctas, y recorridos de interacción mediante pruebas simuladas. No constituye prueba en navegadores o tabletas físicos. Los materiales no son copias de los ejercicios de Teams y las puntuaciones no son notas oficiales.
